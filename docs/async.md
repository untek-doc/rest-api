# Асинхронная обработка запросов

При асинхронной обработке запроса мы не можем получить результат обработки в ответе.
Вместо это команда обработки добавляется в очередь сообщений и обрабатывается в отдельном потоке.
При асинхронной обработке команды мы отвечаем кодом 202 и заголовками Content-Location и Location.

Заголовок Location указывает на URI, где будет размещен запрошенный ресурс (это не состояние), он будет возвращать 404 до тех пор, пока обработка команды не будет завершена. 
Кроме того, содержимое ответа со статус-кодом 202 может включать представление «состояния».
Заголовок Content-Location имеет ссылку на ресурс «состояния», который описывает ход выполнения команды.
